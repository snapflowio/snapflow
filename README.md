## Host a machine

Run this on a Linux machine (amd64 or arm64) with KVM and systemd:

```sh
curl -fsSL https://snapflow.io/install.sh | sh
```

See [docs/hosting.md](docs/hosting.md) for the full requirements and [docs/releases.md](docs/releases.md) for release channels and how to verify downloads.
